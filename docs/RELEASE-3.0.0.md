# Nova Prism 3.0 — Futuristic folder colors / Colori delle cartelle, nuova dimensione

## Italiano
Nova Prism è il nuovo nome di CartelleColorate. Tutte le funzioni sono gratuite.
- Interfaccia futuristica con pannelli sospesi e palette in stile Dock.
- Anteprima 3D chiusa con spessore: trascina per ruotare, doppio clic per ripristinare.
- Colori personalizzati, stili salvati, pipetta e immagini PNG.
- Rinomina, modifica di più cartelle e annullamento.
- Avvio senza terminale e pulsante per ridurre la finestra a icona.

Scarica **NovaPrism-3.0.0-installer-windows.zip**, estrai tutto e apri **Installa.vbs**. Chiudi Nova prima di aggiornare. Il pacchetto CartelleColorate-3.0.0-windows.zip resta disponibile per gli aggiornamenti delle versioni precedenti.
Windows 11/10. L'icona in Esplora file è statica; la rotazione 3D è nell'anteprima dell'app. Lo stile macOS è un tema grafico per Windows.

## English
Nova Prism is the new name of CartelleColorate. All features are free.
- Futuristic interface with floating panels and Dock-style color magnification.
- Closed 3D folder preview: drag to rotate, double-click to reset.
- Custom colors, saved styles, desktop eyedropper and PNG images.
- Folder renaming, batch changes and undo.
- Hidden-console startup and a minimize button.

Download **NovaPrism-3.0.0-installer-windows.zip**, extract everything and open **Installa.vbs**. Close Nova before updating. CartelleColorate-3.0.0-windows.zip remains available for updates from earlier versions.
Windows 11/10. File Explorer icons remain static; 3D rotation is available in the app preview. The macOS style is a visual theme for Windows.
