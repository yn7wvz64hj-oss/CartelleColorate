# CartelleColorate 1.5 — Official Release / Release ufficiale

## English
- Language selection grows from 15 to 35 languages. The original 15 catalogs remain complete; the 20 additions contain translated core controls and are explicitly marked Draft. Advanced tools and missing entries use English. These additions have not been reviewed by native speakers.
- Search languages by native name, English name or language code. Windows’ language is suggested on first launch; exact regional packages and parent-language fallback are supported.
- Import local `.cclang` or JSON language packages and export a template directly from the language dialog. Imported languages persist across restarts and app updates, including right-to-left languages.
- Packages are validated before saving, including translation keys and formatting placeholders. Invalid replacements preserve the previously installed package. Changing languages resets missing interface resources to English instead of retaining text from the previous language.

New draft languages: Turkish, Vietnamese, Thai, Persian, Tamil, Telugu, Marathi, Punjabi, Filipino, Malay, Swahili, Polish, Dutch, Ukrainian, Hebrew, Romanian, Swedish, Greek, Czech and Hungarian.

Open the globe button to search or import a language. All included translations and imported packages work offline. This release does not claim to translate every language in the world; local language packages provide a way to expand the selection.

**Update from 1.3 or newer:** use the update button inside the app. **First installation or older versions:** extract `CartelleColorate-1.5.0-windows.zip`, close the app and run `Installa.cmd`.

## Italiano
- Il selettore passa da 15 a 35 lingue. I 15 cataloghi originali restano completi; le 20 aggiunte traducono i comandi principali e sono indicate come Provvisorie. Gli strumenti avanzati e le voci mancanti usano l’inglese. Le nuove traduzioni non sono state revisionate da madrelingua.
- Ricerca per nome originale, nome inglese o codice della lingua. Al primo avvio viene proposta la lingua di Windows; sono riconosciuti i pacchetti regionali esatti e il ritorno alla lingua di base.
- Importazione di pacchetti locali `.cclang` o JSON ed esportazione di un modello direttamente dal selettore. Le lingue importate restano disponibili dopo riavvii e aggiornamenti, comprese quelle da destra a sinistra.
- Pacchetti verificati prima del salvataggio, comprese chiavi e segnaposti. Un aggiornamento non valido conserva il pacchetto precedente. Quando cambi lingua, le risorse mancanti tornano all’inglese senza mantenere testi della lingua precedente.

Nuove lingue provvisorie: turco, vietnamita, thailandese, persiano, tamil, telugu, marathi, punjabi, filippino, malese, swahili, polacco, olandese, ucraino, ebraico, rumeno, svedese, greco, ceco e ungherese.

Apri il pulsante con il globo per cercare o importare una lingua. Traduzioni incluse e pacchetti importati funzionano senza Internet. Questa versione non traduce tutte le lingue del mondo: i pacchetti locali permettono di ampliare l’elenco.

**Aggiornare dalla 1.3 o successive:** usa il pulsante di aggiornamento nell’app. **Prima installazione o versioni precedenti:** estrai `CartelleColorate-1.5.0-windows.zip`, chiudi l’app ed esegui `Installa.cmd`.
