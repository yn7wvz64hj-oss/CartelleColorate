# CartelleColorate 1.0

## English

The first official release of CartelleColorate for Windows 11. Free and open source under the MIT license.

### Features

- Choose precise colors using the color panel, HEX values or the eyedropper with pixel zoom. Save and rename colors with no app-imposed limit.
- Apply saved colors and favorite presets from the folder’s right-click menu, without opening a terminal.
- Use custom PNG icons through file selection or drag and drop, with cropping and colored badges.
- Compact interface with Windows or glass styling, light/dark themes and 15 languages, selectable on first launch.
- Rename folders, change multiple folder icons, and use Undo and Redo.
- Organize colors into collections, search colors and presets, and browse recently used colors and customized folders.
- Back up the library, including preset PNGs and preferences, and import it while preserving existing local data.
- Background PNG loading and cached, progressive previews for a smoother interface.

### Installation and updates

1. Download **CartelleColorate-1.0.0-windows.zip** from the release assets below.
2. Close the app and extract the entire ZIP.
3. Run **Installa.cmd**.
4. Right-click a folder → **Show more options → Change color**.

Updating from earlier versions preserves saved colors, presets, preferences and backups.
Use **SHA256SUMS.txt** to verify the ZIP.

Automated checks cover all 15 languages, color and PNG icons, history and backups,
launching without a terminal window, favorite presets in the Windows context menu and the update source.

## Italiano

Prima release ufficiale di CartelleColorate per Windows 11. Gratuita e con codice sorgente disponibile sotto licenza MIT.

### Funzioni

- Scegli colori precisi tramite tabella grafica, HEX o pipetta con zoom sui pixel. Salva e rinomina i colori senza un limite imposto dall’app.
- Applica colori salvati e preset preferiti dal tasto destro sulla cartella, senza aprire il terminale.
- Usa icone PNG tramite selezione del file o trascinamento, con ritaglio e contrassegni colorati.
- Interfaccia compatta con stile Windows o vetro, temi chiaro/scuro e 15 lingue selezionabili al primo avvio.
- Rinomina le cartelle, modifica più icone insieme e usa Annulla e Ripeti.
- Organizza i colori in raccolte, cerca colori e preset e consulta colori recenti e cartelle personalizzate.
- Crea un backup della libreria con PNG dei preset e preferenze; importalo conservando i dati locali esistenti.
- Caricamento PNG in background e anteprime progressive memorizzate per un’interfaccia più fluida.

### Installazione e aggiornamento

1. Scarica **CartelleColorate-1.0.0-windows.zip** dagli allegati qui sotto.
2. Chiudi l’app ed estrai tutto il contenuto dello ZIP.
3. Esegui **Installa.cmd**.
4. Tasto destro su una cartella → **Mostra altre opzioni → Cambia colore**.

Aggiornando dalle versioni precedenti, colori, preset, preferenze e backup vengono mantenuti.
Usa **SHA256SUMS.txt** per verificare lo ZIP.

Le verifiche automatiche coprono le 15 lingue, icone colore e PNG, cronologia e backup,
avvio senza finestra del terminale, preset preferiti nel menu Windows e fonte degli aggiornamenti.
