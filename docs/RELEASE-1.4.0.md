# CartelleColorate 1.4 — Official Release / Release ufficiale

## English
- Compare the selected folder’s current Windows icon with the proposed color, PNG and badge before applying. Open ⋯ → Icons → Folder preview, or press Ctrl+P. The preview does not modify the folder.
- Improved automatic contrast for backgrounds and primary buttons. Image backgrounds receive a minimum readability overlay; high-contrast Windows settings use system colors and disable personal backgrounds.
- A shorter right-click color menu shows favorite colors directly and groups the others under More colors. With no favorites, the first five saved colors are shown directly. All saved colors remain available.
- Clear keyboard focus, color selection with arrow keys, and Ctrl+Enter to apply, Ctrl+S to save, Ctrl+F to search, Ctrl+Z to undo and Ctrl+Shift+Z to redo. Text fields retain their own Ctrl+Z behavior. Pop-up fades follow Windows’ reduced-animation setting.
- Updates show download speed and estimated time remaining, with Retry after an error. A stalled download times out after two minutes.
- Reset appearance from the appearance settings restores Windows style, system theme and default backgrounds for both styles, preserving colors, presets, language and folder customizations.

**Update from 1.3:** use the update button inside the app. **First installation or versions up to 1.2:** extract `CartelleColorate-1.4.0-windows.zip`, close the app and run `Installa.cmd`.

Windows application with Windows and macOS appearance styles and 15 interface languages.

## Italiano
- Confronta l’icona attuale della cartella, letta da Windows, con colore, PNG e simbolo proposti prima di applicarli. Apri ⋯ → Icone → Anteprima della cartella, oppure premi Ctrl+P. L’anteprima non modifica la cartella.
- Contrasto automatico migliorato per sfondi e pulsanti principali. Le immagini ricevono una velatura minima per garantire la leggibilità; il contrasto elevato di Windows usa i colori di sistema e disattiva gli sfondi personali.
- Menu dei colori nel tasto destro più corto: preferiti subito disponibili e altri colori raccolti in Altri colori. Senza preferiti, vengono mostrati direttamente i primi cinque colori salvati. Tutti i colori restano accessibili.
- Focus da tastiera visibile, selezione del colore con le frecce e scorciatoie: Ctrl+Enter applica, Ctrl+S salva, Ctrl+F cerca, Ctrl+Z annulla e Ctrl+Shift+Z ripete. Nei campi di testo Ctrl+Z mantiene l’annullamento del testo. Le sfumature dei menu rispettano le impostazioni Windows per ridurre le animazioni.
- Download con velocità e tempo residuo stimato, pulsante Riprova in caso di errore e interruzione dopo due minuti per un download bloccato.
- Ripristina aspetto iniziale nelle impostazioni dell’aspetto riporta stile Windows, tema di sistema e sfondi predefiniti per entrambi gli stili, conservando colori, preset, lingua e cartelle personalizzate.

**Aggiornare dalla 1.3:** usa il pulsante di aggiornamento nell’app. **Prima installazione o versioni fino alla 1.2:** estrai `CartelleColorate-1.4.0-windows.zip`, chiudi l’app ed esegui `Installa.cmd`.

Applicazione Windows con stili grafici Windows e macOS e interfaccia in 15 lingue.
