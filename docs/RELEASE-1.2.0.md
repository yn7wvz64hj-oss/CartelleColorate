# CartelleColorate 1.2 — Official Release / Release ufficiale

## English
- A shorter ⋯ menu groups folder, icon and library tools into submenus.
- Background images now offer positioning, zoom/crop and an adjustable overlay. Preview changes live in the app; Cancel restores your previous background without saving. Each appearance style keeps its own settings, including in portable backups.
- Guided updates show release notes, download the official package on request and verify SHA-256, the file manifest and version before offering Install update. Installation starts only when you select that button; your colors and preferences are retained.
- Dialogs fit the available desktop space and offer scrolling. Compact layouts and rendering at 125%, 150% and 200% have been checked.

The app runs on Windows; macOS is an appearance style. Interface translations are included for all 15 languages. Release notes are provided in English and Italian.

**Install or update:** extract `CartelleColorate-1.2.0-windows.zip`, close the app and run `Installa.cmd`. Right-click a folder → Show more options → Change color.

## Italiano
- Menu ⋯ più corto, con strumenti per cartelle, icone e libreria raggruppati in sottomenu.
- Sfondi con posizione dell’immagine, zoom/ritaglio e velatura regolabile. Le modifiche si vedono subito nell’app; Annulla ripristina lo sfondo precedente senza salvare. Ogni stile conserva le proprie impostazioni, anche nei backup portatili.
- Aggiornamento guidato con note della release, download del pacchetto ufficiale su richiesta e verifica di SHA-256, manifest dei file e versione prima di offrire Installa aggiornamento. L’installazione parte soltanto premendo quel pulsante; colori e preferenze vengono conservati.
- Finestre adattate allo spazio disponibile e contenuti scorrevoli. Verificati layout compatti e rendering al 125%, 150% e 200%.

L’app funziona su Windows; macOS indica uno stile grafico. Interfaccia tradotta nelle 15 lingue. Note della release in italiano e inglese.

**Installare o aggiornare:** estrai `CartelleColorate-1.2.0-windows.zip`, chiudi l’app ed esegui `Installa.cmd`. Tasto destro su una cartella → Mostra altre opzioni → Cambia colore.
