# CartelleColorate 1.3 — Official Release / Release ufficiale

## English
- Update directly inside the app: select **Update now** to download the official package, with a progress bar, percentage and transferred size.
- The package is verified with SHA-256, its file manifest and version before installation. The app closes, installs silently and reopens on the selected folder without opening a browser or terminal.
- Saved colors, presets, backgrounds and preferences are retained. If installation fails, the updater attempts to restore the previous application files.

**Install 1.3 once:** extract `CartelleColorate-1.3.0-windows.zip`, close the app and run `Installa.cmd`. Versions up to 1.2 require this last manual installation; future updates use the new in-app updater. Internet access is needed to download updates.

Windows application with Windows and macOS appearance styles, and 15 interface languages.

## Italiano
- Aggiorna direttamente dall’app: premi **Aggiorna adesso** per scaricare il pacchetto ufficiale, con barra di avanzamento, percentuale e dimensione trasferita.
- Prima dell’installazione vengono verificati SHA-256, manifest dei file e versione. L’app si chiude, installa senza terminale e si riapre sulla cartella selezionata, senza aprire il browser.
- Colori salvati, preset, sfondi e preferenze vengono conservati. Se l’installazione fallisce, il sistema tenta di ripristinare i file della versione precedente.

**Installa la 1.3 una volta:** estrai `CartelleColorate-1.3.0-windows.zip`, chiudi l’app ed esegui `Installa.cmd`. Le versioni fino alla 1.2 richiedono quest’ultima installazione manuale; gli aggiornamenti successivi usano il nuovo sistema integrato. Per scaricare gli aggiornamenti serve Internet.

Applicazione Windows con stili grafici Windows e macOS e interfaccia in 15 lingue.
