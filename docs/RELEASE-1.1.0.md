# CartelleColorate 1.1 — Official Release / Release ufficiale

## English
Personalize the app background independently for the Windows and macOS appearance styles: choose a solid color with the visual picker or HEX, or import a PNG, JPEG or BMP image. Images are stored locally and included in portable library backups.

The app menus and dropdowns now use rounded surfaces, Segoe UI typography and subtle highlights inspired by Windows 11. A download icon beside the appearance selector appears only when a newer version is detected. Update checks run in the background; automatic checks can be disabled in Appearance and glass.

All existing folder colors, PNG icons, presets, language settings and backups are retained. The app runs on Windows; macOS is an appearance style.

**Install or update:** download `CartelleColorate-1.1.0-windows.zip`, extract all files, close the app and run `Installa.cmd`. Right-click a folder → Show more options → Change color. Change the app background from ⋯ → Background.

## Italiano
Personalizza lo sfondo dell’app separatamente per gli stili Windows e macOS: scegli un colore uniforme con tabella grafica o HEX, oppure importa un’immagine PNG, JPEG o BMP. Le immagini vengono conservate localmente e incluse nei backup portatili della libreria.

I menu e i selettori dell’app hanno superfici arrotondate, caratteri Segoe UI ed evidenziazioni discrete ispirate a Windows 11. L’icona di download accanto al selettore dello stile compare solo quando viene rilevata una versione più recente. Il controllo avviene in background; puoi disattivare il controllo automatico in Aspetto e vetro.

Colori, icone PNG, preset, lingua e backup esistenti vengono conservati. L’app funziona su Windows; macOS indica uno stile grafico.

**Installare o aggiornare:** scarica `CartelleColorate-1.1.0-windows.zip`, estrai tutti i file, chiudi l’app ed esegui `Installa.cmd`. Tasto destro su una cartella → Mostra altre opzioni → Cambia colore. Modifica lo sfondo dell’app da ⋯ → Sfondo.
