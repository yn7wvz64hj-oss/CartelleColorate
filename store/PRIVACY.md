# Nova Prism - Privacy / Informativa sulla privacy

Applies to the Microsoft Store edition. / Si applica alla versione Microsoft Store.

## Italiano

Nova Prism personalizza le cartelle selezionate dall'utente. Salva localmente impostazioni, palette, stili e cronologia; crea file icona e configurazioni nelle cartelle personalizzate. I percorsi delle cartelle possono comparire nella cronologia locale. I contenuti delle cartelle, le immagini importate e le palette non vengono inviati a un server da Nova Prism.

La pipetta legge i pixel dello schermo per individuare il colore scelto. Questa funzione non trasmette immagini dello schermo.

La versione Store non include pubblicita, analytics, account, acquisti o attivazione Pro. Il Microsoft Store gestisce distribuzione e aggiornamenti secondo l'informativa Microsoft. Aprendo collegamenti esterni, come supporto su GitHub, si applicano le informative dei rispettivi servizi. I dati inseriti volontariamente in una segnalazione pubblica GitHub possono essere visibili pubblicamente: evita di includere percorsi o documenti personali.

I dati locali sono conservati per utilizzare palette e annullamento. Puoi rimuovere le palette e la cronologia dall'app. La disinstallazione non ripristina automaticamente le icone delle cartelle gia personalizzate: ripristinale dall'app prima della disinstallazione se lo desideri.

Per richieste relative all'app usa il supporto del progetto: https://github.com/yn7wvz64hj-oss/CartelleColorate/issues.

## English

Nova Prism customizes folders selected by the user. It stores settings, palettes, styles and history locally, and creates icon and configuration files in customized folders. Folder paths may appear in local history. Nova Prism does not upload folder contents, imported images or palettes to a server.

The eyedropper reads screen pixels to obtain the selected color. It does not transmit screen images.

The Store edition includes no advertising, analytics, accounts, purchases or Pro activation. Microsoft Store handles distribution and updates under Microsoft's privacy policy. External links, including GitHub support, are subject to those services' privacy policies. Information you voluntarily post to public GitHub issues may be publicly visible; avoid including personal paths or documents.

Local data is retained for palettes and undo. Palettes and history can be removed from the app. Uninstalling does not automatically restore customized folder icons. Restore them in the app before uninstalling if desired.

For app-related requests, use project support: https://github.com/yn7wvz64hj-oss/CartelleColorate/issues.
